# Politique de securite

## Versions supportees

Kapsule est en developpement actif ; seule la branche `main` recoit des
correctifs de securite.

## Signaler une vulnerabilite

Merci de **ne pas** ouvrir d'issue publique pour une faille de securite.

- Utilisez l'onglet **Security > Report a vulnerability** du depot GitHub
  (advisory prive), ou
- contactez les mainteneurs via un canal prive indique dans le profil du depot.

Merci d'inclure : une description, les etapes de reproduction, l'impact estime
et, si possible, une suggestion de correctif. Nous accusons reception sous 72 h
et visons un correctif ou un plan de mitigation sous 30 jours.

## Bonnes pratiques attendues

- Ne partagez jamais de secret (cle, token, mot de passe) dans une issue, une PR
  ou un document du depot.
- Les preuves d'exploitation doivent etre non sensibles et anonymisees.

## Perimetre

Sont concernes : l'API backend, le frontend PWA, la chaine de build et de
deploiement. Les decks de contenu fournis a titre d'exemple ne sont pas dans le
perimetre de securite.
